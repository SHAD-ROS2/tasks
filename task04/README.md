# L04 Gazebo и смысл данных симуляции

Сначала на лекции разбираем теорию. Затем на практике преподаватель показывает запуск, вы повторяете его на том же учебном комплекте. После занятия выполняете отдельную домашнюю работу и сдаёте её в личный приватный репозиторий.

- [Практика на 90 минут](docs/Practice_L04.md)
- [Самостоятельное домашнее задание](docs/Homework_L04.md)
- [Контракт интерфейсов и измерений](docs/CONTRACT.md)

Среда: Docker, Ubuntu 24.04, ROS 2 Jazzy, Gazebo Harmonic. ROS на хосте устанавливать не нужно. Учебная двухколёсная платформа L04 независима от домашнего задания L03.

## До занятия

Из общего репозитория откройте `task04/`. Преподаватель выполняет эти же команды из `day-04/student/` в internal.

```bash
./course up
./course doctor
./course build
./course desktop
```

Первый запуск собирает образ и скачивает зависимости. Выполните его до практики. `desktop` выводит адрес рабочего стола в браузере. Все команды второго терминала также выполняются из `task04/`.

## Практика

```bash
./course practice
```

В браузере откройте адрес, напечатанный `./course desktop`. Следуйте [руководству практики](docs/Practice_L04.md). Для проверки без окон сначала остановите интерактивный запуск через Ctrl+C, затем выполните:

```bash
./course check --mode practice --output evidence/practice-check.json
```

`check` самостоятельно поднимает свежий headless стенд и завершает его. `observe` и `scenario` работают с уже запущенной сценой. Одновременно используйте один запуск в одном ROS domain и Gazebo partition.

## Домашняя работа

Откройте `task04/` в своём личном репозитории. Измените три файла, указанные в [условии](docs/Homework_L04.md), добавьте собственный тест и объяснение. Готовый практический запуск не является домашней сдачей. До заполнения TODO домашний запуск сообщает о незавершённой конфигурации; это ожидаемое состояние starter.

```bash
./course build
./course test
./course check --mode homework --output evidence/homework-check.json
```

Сохраните решение, тест, evidence и diagnosis в `task04/`, сделайте commit и push в личный приватный репозиторий. Дедлайн объявляет преподаватель; время дедлайна в этом комплекте не задано. По правилам курса проверяется последний commit в `master` на дедлайн. Преподаватель выполняет свою проверку и выставляет оценку.

## Завершение и помощь

Остановите запущенный launch через Ctrl+C, затем выполните `./course down`. Команда останавливает окружение этого задания. При ошибке сохраните полный вывод, результат `./course doctor`, версию Docker и точную команду запуска.

```bash
./course exec ros2 topic list -t
./course exec gz topic -l
docker compose logs --tail=100 workspace
```

Камера и LiDAR используют графический движок даже без окон. Образ настраивает software rendering; фактический RTF зависит от компьютера. Вывод `check` и сохранённый log помогают отличить проблему окружения от ошибки решения.
