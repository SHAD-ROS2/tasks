Заполните этот файл и закоммитьте его вместе с решением. Это короткая запись
самопроверки для обратной связи: авто-грейдер её не разбирает и отдельных баллов
за неё нет. Полные логи тестов сюда копировать не нужно. Student ID и Commit SHA
не указывайте — преподаватель автоматически фиксирует последний коммит `master`,
отправленный в ваш private-репозиторий к дедлайну.

Замените текст в угловых скобках; достаточно 5–10 строк собственных ответов.
